# 9×9 乘法表 GUI 版本

## 功能
- 漂亮的 Tkinter 圖形介面
- 一鍵複製表格內容到剪貼簿
- 可打包成單一 Windows .exe 執行檔（無需安裝 Python）

## 如何執行
1. 安裝 Python 3.8+
2. `pip install tkinter` （Windows 通常已內建）
3. `python multiplication_table_gui.py`

## 如何打包成 .exe
1. 雙擊 `build_exe.bat` 
2. 完成後在 `dist` 資料夾找到 `multiplication_table_gui.exe`

打包後的 .exe 可以直接在沒有 Python 的 Windows 電腦上執行！
